# Grand Royal Restaurant Website

A luxury restaurant reservation and dining experience website built using:

* Next.js
* React
* TypeScript
* Tailwind CSS

## Features

* Luxury Hero Section
* Featured Dishes
* Interactive Menu
* Online Table Reservation
* Gallery
* Customer Testimonials
* Contact Form
* Premium Footer
