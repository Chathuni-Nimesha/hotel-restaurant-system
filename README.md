# Hotel Restaurant System

A full-stack Hotel & Restaurant Reservation System developed using modern web technologies.

## Features

* Restaurant reservation booking system
* Admin reservation dashboard
* Reservation management (View & Delete)
* Responsive user interface
* MongoDB database integration
* REST API architecture

## Technologies Used

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express.js
* TypeScript

### Database

* MongoDB Atlas
* Mongoose
