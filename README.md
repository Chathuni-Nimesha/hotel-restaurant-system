# 🍽️ Grand Royal Hotel Restaurant Management System

A modern full-stack Hotel & Restaurant Management System developed using **Next.js, React, Node.js, Express.js, MongoDB, and TypeScript**. The system provides an efficient solution for managing restaurant reservations and menu items through a responsive admin dashboard.

---

## ✨ Features

### Reservation Management
- Restaurant reservation booking
- Reservation CRUD operations (Create, Read, Update, Delete)
- Reservation dashboard
- Reservation search
- Reservation status filter
- Reservation sorting
- Dashboard statistics
- Reservation status management

### Menu Management
- Menu CRUD operations
- Add new food items
- Edit existing menu items
- Delete menu items
- Menu dashboard statistics
- Image URL support
- Availability status management

### General Features
- Responsive admin dashboard
- RESTful API architecture
- MongoDB Atlas database integration
- Modern UI with Tailwind CSS
- Full-stack architecture using React and Express
